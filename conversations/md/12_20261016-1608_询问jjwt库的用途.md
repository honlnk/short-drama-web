这个会话中 提到的 jjwt 是干什么的？

### 🤖 AI

在那个会话里，**jjwt 是一个 Java 的 JWT（JSON Web Token）库**（`io.jsonwebtoken` 出品），计划用于本项目后端的登录鉴权，具体用途是：

- **签发 token**：用户注册（`POST /api/auth/register`）或登录（`POST /api/auth/login`）成功后，生成一个包含 userId、username、role 的 JWT 返回给前端；前端持久化令牌，后续请求带上它维持会话。
- **解析校验 token**：配套规划了 `security/JwtService`（签发/解析/校验）和 `security/JwtAuthFilter`（从 `Authorization: Bearer xxx` 头里解析 token 塞进 SecurityContext），用来替换现在 `SecurityConfig.java` 里脚手架临时态的「全量放行」。

引入它是因为需求（PRD US-02/US-03）要求注册/登录走 JWT 无状态鉴权，计划加的依赖坐标是 `jjwt-api / jjwt-impl / jjwt-jackson:0.12.x`，并配 `app.jwt.secret` 和 `app.jwt.expire-hours`（建议 72 小时）两项配置。

需要说明的是，截至那个会话结束，jjwt **还停留在计划阶段**——`pom.xml` 里并没有加这个依赖，`application.yml` 也没有 jwt 相关配置。它是第二阶段「用户链路」待办的第一步，只等当时那次方案拍板。
