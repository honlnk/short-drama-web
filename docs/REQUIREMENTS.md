# AI Coding 现场实战题

> 来源：需求题面照片（IMG_20261016_144836.jpg），以下为题面文字整理。

## 一、命题：短剧 APP

请使用你熟悉的 **AI Coding 工具**，开发一个类似「红果短剧」的简化版短剧 Web APP 或 APP。

## 二、基础要求

1. 后端使用 **Java**
2. 前端使 **React 或 React EXPO**（如果熟练度允许可以使用 **React Native 或 Flutter** 最佳）
3. 包含**用户注册、登录**
4. 包含**短剧内容展示**
5. 包含**点赞、收藏**等基础用户功能
6. 包含**管理后台**，可对短剧内容进行**增删改查**
7. 前后端及数据库**真实打通**，最终项目可以**正常运行并现场演示**

除此之外，产品设计、页面设计、数据库设计、技术架构、功能扩展、开发方式及 AI Coding 工具均由候选人自行决定和发挥。

## 三、最终提交

完成后现场演示项目，并简单介绍自己的设计思路和 AI Coding 开发过程。
